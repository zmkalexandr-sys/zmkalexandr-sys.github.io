Как записать пульт BFT MITTOBFT MITTO пультін қалай жазуға боладыHow to program a BFT MITTO remote

Пульты BFT MITTO работают с динамическим кодом 433,92 МГц. Они не копируются друг с друга и дубликатором, а записываются в приёмник блока управления.BFT MITTO пульттері 433,92 МГц динамикалық кодпен жұмыс істейді. Олар бір-бірінен және көшірме пультпен көшірілмейді, басқару блогының қабылдағышына жазылады.BFT MITTO remotes use a 433.92 MHz rolling code. They are not copied from each other or by a copy remote; they are stored in the control unit's receiver.

Запись через меню блока с дисплеемДисплейі бар блок мәзірі арқылы жазуProgramming via the display menu

1

Откройте менюМәзірді ашыңызOpen the menu

Нажмите OK, появится приветствие BFT. Нажмите OK ещё раз, появится раздел PARAMETER.OK басыңыз, BFT сәлемдесуі шығады. OK тағы басыңыз, PARAMETER бөлімі шығады.Press OK to see the BFT greeting. Press OK again to see PARAMETER.

2

Раздел RadioRadio бөліміRadio section

Нажимайте «−», пока не появится Radio. Нажмите OK: появится ADD Start. Нажмите OK: на дисплее hidden button.Radio шыққанша «−» басыңыз. OK басыңыз: ADD Start шығады. OK басыңыз: дисплейде hidden button.Press “−” until Radio appears. Press OK: ADD Start appears. Press OK: the display shows hidden button.

3

Скрытая кнопкаЖасырын батырмаHidden button

Нажмите одновременно две кнопки пульта. На дисплее появится release, затем desired button.Пульттің екі батырмасын бір мезгілде басыңыз. Дисплейде release, содан кейін desired button шығады.Press two remote buttons together. The display shows release, then desired button.

4

Нужная кнопкаҚажетті батырмаDesired button

Нажмите кнопку, которой будете открывать. Появится OK 01: пульт записан.Ашатын батырманы басыңыз. OK 01 шығады: пульт жазылды.Press the button you will use to open. OK 01 appears: the remote is stored.

5

Следующие пультыКелесі пульттерMore remotes

Для каждого следующего пульта повторите шаги 3 и 4.Әр келесі пульт үшін 3 және 4-қадамдарды қайталаңыз.Repeat steps 3 and 4 for each remote.

6

ВыходШығуExit

Дважды нажмите одновременно «+» и «−». Проверьте работу ворот.«+» және «−» батырмаларын бір мезгілде екі рет басыңыз. Қақпаның жұмысын тексеріңіз.Press “+” and “−” together twice. Test the gate.

Блоки управления без дисплея и внешние приёмники BFT записывают пульты по-другому. Пришлите фото блока, и мы подскажем порядок для вашей модели.Дисплейі жоқ басқару блоктары мен BFT сыртқы қабылдағыштары пульттерді басқаша жазады. Блоктың фотосын жіберіңіз, сіздің модельге арналған тәртіпті айтамыз.Control units without a display and external BFT receivers use a different procedure. Send a photo and we will advise for your model.

Перед проверкой убедитесь, что в проёме ворот или под стрелой шлагбаума нет людей и машин. Работы внутри блока управления выполняет только специалист: там напряжение 230 В.Тексеру алдында қақпа ойығында немесе шлагбаум жебесінің астында адамдар мен көліктер жоқ екеніне көз жеткізіңіз. Басқару блогының ішіндегі жұмыстарды тек маман орындайды: онда 230 В кернеу бар.Before testing, make sure no people or cars are in the gate opening or under the barrier boom. Work inside the control unit is for a technician only: it carries 230 V.

Часто задаваемые вопросыЖиі қойылатын сұрақтарFrequently asked questions

Можно скопировать пульт BFT универсальным дубликатором?BFT пультін әмбебап көшірме пультпен көшіруге бола ма?Can a universal copy remote clone a BFT remote?

Нет. У MITTO динамический код, дубликатор его не повторит. Новый пульт записывают в приёмник.Жоқ. MITTO динамикалық кодпен жұмыс істейді, көшірме пульт оны қайталай алмайды. Жаңа пульт қабылдағышқа жазылады.No. MITTO uses a rolling code that a copy remote cannot repeat. A new remote is stored in the receiver.

Подойдёт ли инструкция для MITTO COOL?Нұсқаулық MITTO COOL үшін жарай ма?Does this apply to MITTO COOL?

MITTO COOL совместим с приёмниками серии MITTO, но порядок записи уточняйте по модели блока. Напишите нам.MITTO COOL MITTO сериясының қабылдағыштарымен үйлесімді, бірақ жазу тәртібін блок моделі бойынша нақтылаңыз. Бізге жазыңыз.MITTO COOL works with MITTO receivers, but check the procedure for your unit. Message us.
